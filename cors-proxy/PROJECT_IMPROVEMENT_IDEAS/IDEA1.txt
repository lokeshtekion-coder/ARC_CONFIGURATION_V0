
### 1. Data Sync Bot (`dataSyncBot.ts` & `SyncBotDashboard.tsx`)

* **Autonomous Conflict Resolution**:
* Instead of waiting for manual review when local state and remote Excel diverge,
enable the bot to resolve non-breaking conflicts automatically based on change timestamps or
department priority rules.

* **Proactive Status Alerts via Slack**:
* Wire the bot directly to `storeSlackHelper.ts`. Whenever it detects a store moving from `WIP` to `Completed`,
or when a launch date enters the $T$-7 window, it can automatically draft or dispatch a notification to
the assigned conversion leads.

* **Scheduled Cron / Headless Background Sync**:
* Move execution or triggers to the Express backend (`cors-proxy`) using a lightweight cron job or
queue so synchronization runs on a schedule even when no user has the frontend browser tab open.


* **Automated Rollback & Audit Logging**:
* Have the bot maintain an append-only transaction log of every cell mutation, letting you run
a one-click rollback if an accidental bulk edit corrupts a sheet.

### 2. Blueprint Decode Bot (`blueprintDecodeBot.ts`)

* **Automated Blueprint Validation**:
* Currently, the bot primarily parses and visualizes question trees. You can expand it to
run automated assertion checks (e.g., verifying that all required accounting sign-offs, parts price breaks,
and service opcode prerequisites are completed before allowing a launch status to flip to `Ready`).

* **Cross-Store Blueprint Cloner**:
* Enable the bot to take a validated "Gold Master" blueprint from an established dealership and
automatically generate the configuration payload for a newly onboarding dealer within the same brand/OEM.


* **Live Blueprint-to-GLAM Diffing**:
* Let the bot cross-reference blueprint responses against active GL accounts (`GLAM.tsx`) and
automatically highlight missing ledger numbers or unmatched departmental categories.

---

### 3. TGPT Assistant (`/src/pages/TGPT/`)

* **Tool Calling / Function Calling Agent**:
* Give TGPT direct tool access to your codebase services. Instead of just answering text prompts,
let it execute actions like:
* `"Update dealership 6248 Fixed Ops to Completed"` $\rightarrow$ calls `patchSingleStoreStatusInGraph`.

* `"Show all stores launching in the next 14 days with incomplete parts sign-offs"` $\rightarrow$ queries
`storesDb.ts`.

* `"Fetch setup data for all T-30 stores"` $\rightarrow$ invokes `fetchSetupDataForStore`.



* **Automated Slack Follow-Up Writer**:
* Allow TGPT to generate tailored dealer outreach messages based on missing onboarding tasks,
formatting the text directly for the `DealerMetaModal` dispatch.


---

### 4. Bot Health Endpoint (`botHealth.route.ts`)

* **Dead Token & Session Alerting**:
* Expand the endpoint to actively probe the expiration time of your captured Graph API and
Tekion tokens. If a token has less than 30 minutes remaining, it can emit a warning badge or
send a ping before synchronization fails silently.


* **Auto-Recovery**:
* If a Graph API network call fails due to throttling (HTTP 429/503), have the health monitor
coordinate an exponential backoff retry rather than abandoning the job.
