## Suggested first bot spec

### GL Audit Bot
Input:
- saved bootstrap snapshot
- decoded blueprint/accounting tokens
- salesChains decoded rows

Logic:
- match token against:
  - `accountNumber`
  - exact `id`
  - exact `key`
  - suffix of `id`
  - suffix of `key`
- produce:
  - confidence
  - matched account
  - reason

Output:
- UI table
- downloadable CSV
- summary counts

Example statuses:
- Exact Account Number Match
- ID Suffix Match
- Key Suffix Match
- No Match
- Multiple Matches

## Security note
If you build a bot for this project:

### Safe
- process bootstrap snapshots
- process normalized data
- audit mappings
- report missing fields

### Be careful
- don’t make the bot dump raw tokens
- don’t log auth headers
- don’t persist secrets unnecessarily
- don’t let the bot act on Slack/Graph/Tekion credentials unless required
